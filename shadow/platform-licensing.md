# PENDING Platform / White Label

Future licensing route for banks, insurers, retailers, membership organisations and employee-benefit providers.

Possible models:
- co-branded PENDING
- white-label experience
- embedded Money Sweep
- embedded resolution tracker
- PENDING Promise integration
- API access
- implementation/support contract

Non-negotiables:
- clear data controller/processor roles before launch
- user consent and privacy controls
- no silent cross-client data sharing
- PENDING outcome integrity cannot be purchased
- enterprise customisation must not corrupt core consumer records
