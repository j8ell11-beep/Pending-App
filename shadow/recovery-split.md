# Split My Recovery

A recovered amount can be allocated across multiple purposes rather than one destination.

Example: £250 recovered
- £100 debt
- £75 emergency fund
- £50 holiday goal
- £15 personal/treat
- £10 giving

## Modes
- Fixed amount split
- Percentage split
- Saved split template for future recoveries
- Manual adjustment before confirmation
- Unallocated remainder allowed

## Accounting rules
- Sum of recovery allocations cannot exceed the actual recovered amount.
- User-funded PENDING Boost remains separate and cannot inflate recovered totals.
- A saved percentage split is a suggestion only; user confirms it for each recovery.
- PENDING records allocation intent; it does not claim money was transferred between bank accounts.

Proposed UI label: **SPLIT MY RECOVERY**
